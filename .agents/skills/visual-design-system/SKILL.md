# Visual design and clean CSS
Read docs/design-reference.png. Build a premium blush/beige cosmetics store with editorial images, airy typography, intuitive mobile-first navigation, product details, and clear checkout. Do not copy reference brand assets. Avoid excessive generic AI-style cards, heavy gradients, glassmorphism, random icons, and unnecessary admin panels. Use CSS custom properties for tokens; CSS Modules or consistently scoped styles, Flexbox/Grid, responsive breakpoints, semantic markup and accessibility. Favor composition, spacing, and content hierarchy over ornament. Use component composition, custom hooks, container/presentation separation and a checkout state reducer when useful; never force patterns without a concrete benefit. Test narrow mobile viewport and desktop. Explain notable decisions in Spanish.
